# 🌐 Projeto GeoTrack — Logística e Energia Geotérmica

Site temático desenvolvido para representar uma empresa **fictícia** do setor de **logística de materiais para a indústria da energia geotérmica**.

🔗 **Acesse o site:** [rafaeldegino.github.io/GeoTrack](https://rafaeldegino.github.io/GeoTrack/)

---

## 🏢 Sobre o Projeto

A proposta foi criar uma identidade digital para a **GeoTrack**, uma empresa fictícia criada com o objetivo de simular a presença online de uma companhia moderna e tecnológica, voltada para soluções de logística no setor de energia sustentável.

---

## 🧰 Tecnologias e Destaques
✅ HTML5 e CSS3 para estrutura e visual do site

✅ Navegação simples e intuitiva

✅ Simulação de presença corporativa online

✅ Foco em design institucional

✅ Uso de imagens, ícones e conteúdo informativo

✅ Site 100% responsivo
